# LoRA Panel Studio

ChatGPTで作成したキャラクター資料を、パネルごとに切り出し、通常リサイズまたはAIで拡大する静的Webアプリです。画像はブラウザ内で処理し、外部送信しません。分割・比較・AI拡大・ZIP保存を同じ作業画面にまとめています。

## 起動

Windowsでは、このフォルダーの「起動.cmd」を実行してください。Node.jsで静的ファイルを配信し、http://127.0.0.1:8765/ を開きます。配信プロセスの終了はCtrl+Cです。既にプレビューが動いている場合はそのURLを開いてください。

AI推論はブラウザ内で行います。Node.jsは開発用の静的配信にだけ使用し、画像を受信する推論サーバーではありません。このフォルダー全体をHTTPSの静的Webサイトに配置すれば、利用者側のNode.jsは不要です。公開は未実施です。Chrome / Edgeの新しいバージョンを推奨します。

AIはHTTPSまたはlocalhostで使用してください。通常の分割・リサイズは単一index.htmlにも含まれますが、AIにはsrc・vendor・modelsの同梱ファイルも必要です。file://直開きは検証ブラウザのポリシーにより未検証で、AIモードではHTTP/HTTPSで開く案内を出します。

まず「添付サンプルを試す」を押すと、今回の資料画像に手動で定義した43枠が表示されます。カラーパレットは含まず、Chibiは既定で書き出し対象から外した42枚です。自動検出の成功例ではなく、切り出しと拡大の操作を試すための参考設定です。

## ChatGPTで素材を作る

1. 「生成プロンプト」で表情・顔の三面図・全身の三面図・髪や衣装の詳細・顔の向き追加・動作ポーズを選びます。
2. 必要なら行数・列数、マスの内容、キャラクターの固定仕様を変更します。
3. 「コピー」を押し、ChatGPTに参照画像とともに貼り付けます。
4. 生成画像をダウンロードして、アプリで開きます。
5. 「この行列・色を分割設定に反映」で指定を揃え、「枠線から自動分割」を押します。

プロンプトには、キャラクターを問わない共通ルールを常に含めます。

- 1マス＝1つの絵: 1マスに1視点・1構図・1人。マス内部の再分割、小窓、挿図、比較図、部品図、内部の区切り線を禁止。
- 特徴の固定: 髪型・装飾品の個数と取り付け位置・衣装の構造を変更・追加・省略しない。左右はキャラクター本人基準。角度で隠れる装飾を移動・複製しない。
- 背景: 全マス同じ無地の明るいニュートラルグレー。表情や向きで背景色を変えない。
- 画角: 顔（頭頂〜肩の上端）・全身（頭頂〜足先）・部位接写をプリセットごとに明示。

「キャラクターの固定仕様」は共通ルールを置き換えず、追加の仕様として付け加えます。崩れやすい装飾の個数・左右などをキャラクターごとに書いてください（例: 髪飾りは本人の右側に1つ）。同じシートに向きや動作を詰め込まず、顔の向き追加・動作ポーズは別シートで生成します。効果は同じ基準画像で再生成して確認してください。

参考キャンバスは1024×1024、1536×1024、1024×1536。これらはOpenAIの画像API公式資料で示される標準候補を参考にしています。APIのパラメーター指定とChatGPTの会話による指示は異なり、ChatGPTの出力画素数・線幅・グリッド配置を保証するものではありません。アプリは実際の画像の幅と高さを読み取って処理し、参考寸法以外も受け付けます。

- [OpenAI画像生成公式資料](https://developers.openai.com/api/docs/guides/image-generation)
- [ChatGPTでの画像生成](https://learn.chatgpt.com/docs/image-generation)
- 確認日: 2026-10-03 Asia/Tokyo

線幅は短辺の0.6〜1%を目安として指示しますが、検出処理は実際に検出した線の幅を使います。絵に使わないマゼンタ等の専用色、連続した外周と区切り線、文字なしの少数マスを推奨します。顔と全身を同じ一覧に詰め込まず、シートを分けると細部を確保しやすくなります。

## 分割・調整

- 自動分割: 指定色に近い画素を集め、画像全体の行・列に占める割合から水平・垂直線を検出します。期待する本数（列数+1、行数+1）と一致しなければ既存枠を変更せずエラーを表示します。線の内側から指定余白を引いて切り出します。
- 検出の調整: 色の許容差や線の連続率を調整できます。絵の中に同色の長い線があると誤検出する可能性があります。
- 均等グリッド: 行列数で画像を等分します。実際の配置ずれはプレビューで確認してください。
- 手動追加: 「枠を追加」を押し、画像上をドラッグします。
- 修正: 枠やプレビューをクリックして選択。枠をドラッグして移動、角をドラッグしてサイズ変更。右側の数値でも座標と寸法を入力できます。
- 微調整: 画像にフォーカスがあるとき矢印キーで1px、Shift+矢印で10px移動。変更を戻すには「元に戻す」。
- 出力選択: パネル一覧のチェックを外した枠はZIPに入りません。

薄い装飾罫線、途切れた線、サイズが混在する自由レイアウトは自動検出の対象外です。手動枠を保存するか、生成条件を揃えてください。被写体の意味認識、文字の自動消去は実装していません。

## 保存

出力長辺は原寸・512・768・1024・1536・2048px。縦横比を維持し、「正方形」を選ぶと明るい背景の余白を足します。被写体を引き伸ばしたり、自動的に切り落としたりしません。原寸でも正方形指定は最大辺まで余白を追加します。

通常リサイズでは、元の細部は増えません。AIモードはアニメ向けReal-ESRGAN animevideov3を使い、原寸の切り出しを入力として2倍または4倍にします。2倍の場合も4倍モデルで推論した後に縮小します。AIの後で1024pxなどへの追加拡大は行いません。

## 同じ画面でAI拡大

1. 素材を分割し、パネルをクリックして選びます。
2. 「選択中をAI拡大」で1枚を試します。自動的にAIモードに切り替わります。
3. 左の出力設定で2倍 / 4倍、GPU優先 / CPU、正方形の余白を指定できます。
4. 通常リサイズとAIの結果を同じ寸法・表示倍率で比較します。
5. チェックした素材を「対象を一括AI拡大」で順番に処理します。「停止」は現在の推論も中断し、完了済みの結果を保持します。
6. 「PNG保存」または「ZIPで一括保存」。AIモードで未処理の対象があれば、保存前に処理します。

GPU優先でWebGPUを利用できない場合はWASMのCPUに切り替え、実際のエンジンを表示します。一括拡大の個別エラーは表示して次に進みますが、ZIP保存では失敗した画像を通常リサイズで代用せず保存を止めます。

AI結果は元画像・切り出し座標・倍率・余白・処理設定に紐づけて保持します。座標を変えると再処理が必要です。取り消しで元の座標に戻すと保持済みの結果を再利用できます。「AI結果を消す」または新しい画像の読み込みで消去できます。

AIは細部を推定するため、線や顔・装飾の特徴が変わることがあります。LoRA学習での品質・人物の一致を保証する機能ではありません。比較して採用してください。

ZIPの内容:

```text
resized/             出力サイズのPNG
                     トリガーワードまたはキャプションがある場合、同名TXT
originals/           原寸の切り出しPNG（選択時）
contact-sheet.png    原寸の切り出しから作る確認用一覧
manifest.json        元画像・座標・寸法・倍率・モデルとハッシュ・実行エンジン
panel-template.json  再利用用の全枠・選択状態・出力設定
```

「設定を保存」からテンプレートだけ保存できます。画像は含まれません。設定を読み込むと正規化座標で現在の画像に配置します。同じ縦横比でも生成配置は変わるため確認してください。縦横比が異なる場合は注意を表示します。`assets/sample-template.json` は添付画像用の参考設定です。

ブラウザを閉じると編集内容は消えます。再開する場合はテンプレートJSONを保存して、元画像とともに保管してください。保存先はブラウザのダウンロード設定に従います。

## 制限

- PNG / JPEG / WebP、35MB以下、各辺8192px以下、合計3600万画素以下。
- 最大80枠。出力PNGと原寸PNGを合わせて1回の保存は合計1.6億画素まで。
- AI: 原寸1パネル400万画素以下、出力各辺8192px以下。AI出力の保持は合計6400万画素以下。正方形の余白も画素数に含めます。
- これらはアプリのメモリー保護用制限であり、ChatGPTの生成仕様ではありません。
- 画像・テンプレートを外部に送信せず、API接続・課金・テレメトリーはありません。
- 試作版。LoRA学習と学習素材の自動品質判定は含みません。

## 開発・引き継ぎ

Node.js 24で検証。ビルドとテスト用のnpm installは不要。AI用の固定ランタイムとモデルをvendor / modelsに同梱しています。

```powershell
node verify-assets.mjs
node --test tests/*.test.cjs
node --check src/app.js
node build.mjs
```

`src/ai-core.js` がAIタイルと寸法、`src/ai-worker.js` がWorkerでの推論、`src/core.js` が座標・検出・設定検証の正本、`src/zip.js` がZIP処理、`src/app.js` が画面とCanvas処理です。`src/shell.html` と `src/style.css` を含めて `build.mjs` が単一の `index.html` を生成します。生成後のHTMLを直接修正せず、ソースを変更して再ビルドしてください。

開発規則は `AGENTS.md`、計画は `DEVELOPMENT_PLAN.md`、最新の検証・既知の制約は `DEVELOPMENT_STATUS.md` を参照してください。Git未使用。公開・pushは実施していません。

- Real-ESRGAN animevideov3（BSD-3-Clause）: models/LICENSE-Real-ESRGAN.txt。
- ONNX形式はningtoba/Browsersnip-Upscaleの固定コミット8e7094416ad91ec7477e968d348cd78742e20dc6の変換済みデータ。Real-ESRGAN公式のONNX配布物ではありません。変換スクリプトは上流が公式重みからのexportと数値比較を記載。当アプリではモデルSHA256と入出力形状を確認して推論します。
- 出典・固定版・バイト数・SHA256はassets/ai-assets.json、再検証はnode verify-assets.mjs。
- [ONNX Runtime Web](https://onnxruntime.ai/docs/tutorials/web/) / [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) / [ONNX変換元](https://github.com/ningtoba/Browsersnip-Upscale/tree/8e7094416ad91ec7477e968d348cd78742e20dc6)

最初のモデル・ランタイム読み込みも同じWebサイトからのGETです。画像アップロード・外部CDN・APIキーは使用しません。HTTPSサイトでは初回に約28MBのAIデータを読み込むため、そのデータ配信にはネット接続が必要です。localhostでは同梱ファイルを読み込み、ネット接続なしでAI処理できます。
